# Admin Dashboard Routes (Phase 2)

**Status:** ✅ Backend Implementation Complete  
**Date:** 2026-08-13  
**Implementation:** Express.js + Prisma ORM  

---

## Overview

Complete RESTful API for admin dashboard operations covering:
- 📊 Company analytics & financial tracking
- 👥 Driver management & suspension
- 💰 Payment/payout history
- 📈 Campaign performance monitoring
- 📋 Lead tracking

All routes require JWT authentication with `ADMIN` role.

Suspend a driver (remove from platform).

**Request Body:**
```json
{
  "reason": "Multiple complaints from passengers"
}
```

```json
{
  "data": {
    "status": "suspended"
  }
}
```

### POST `/admin/drivers/:id/activate`
Reactivate a suspended driver.

**Response:**
```json

  }
}
```

## Implementation Notes

### Database Queries
- All queries use `prisma.$transaction()` to prevent connection pooling issues
- Soft deletes respected everywhere (`deleted_at: null`)
- Multi-tenant isolation via `company_id` field
- Proper indexing on `motorista_id`, `status`, `company_id`

### Pagination
- `page` defaults to 1 (min 1, max unlimited)
- `limit` defaults to 50 (min 1, max 200)
- Response includes `total`, `page`, `limit`

### Data Types
- Decimal fields (Prisma) converted to `Number` with `.toFixed(2)`
- Dates returned as ISO 8601 strings
- All enum values in correct case (PT-BR where applicable)

### Audit Trail
- `suspendDriver` and `activateDriver` create AuditLog entries
- Resource type: `MotoristaProfile`
- Action: `UPDATE`
- Captures old/new values for compliance

```bash

  http://localhost:3000/admin/companies

curl -H "Authorization: Bearer TOKEN" \

curl -H "Authorization: Bearer TOKEN" \
  http://localhost:3000/admin/drivers/:id

# Suspend driver
curl -X POST \
  -H "Authorization: Bearer TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"reason":"Multiple complaints"}' \
  http://localhost:3000/admin/drivers/:id/suspend
```

- `companyDetail(companyId)`
- `companyLeads(companyId, page, limit, filters)`
- `companyFinancial(companyId)`
- `driverDetail(motoristaId)`
- `driverEarnings(motoristaId, page, limit, filters)`
- `driverSessions(motoristaId, page, limit)`
- `driverStats(motoristaId)`
- `driverPayouts(motoristaId, page, limit)`

- `activateDriver(adminUserId, motoristaId)`
