🚀 COMO USAR (Local Development)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Primeira vez:

   docker compose up -d         # Start PostgreSQL
   npm run db:dev              # Setup + seed (1 comando)

2. Verificar:

   npm run db:studio           # Visual browser (http://localhost:5555)
   curl http://localhost:3000/health  # API health

3. Desenvolver:

   npm run dev                 # Backend API
   cd frontend && npm run dev  # Frontend (new terminal)

4. Testar (Phase 2):

   npm run test:unit           # Jest
   npm run test:e2e            # Playwright
   npm run test:coverage       # Coverage report

5. Limpar (quando necessário):

   docker compose down -v      # Wipe everything

Tempo total: ~2 minutos para setup completo
